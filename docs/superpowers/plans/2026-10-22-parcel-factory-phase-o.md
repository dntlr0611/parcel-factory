# Parcel Factory Phase O — 여러 공장 (스펙 §19)

큰 리팩토링이다. 순서를 지키고 각 단계마다 기존 테스트가 통과하는 상태를 유지한다.

## O1 — 코어 분리 (동작 변화 없음)
- `GameSession`에서 회사 공유(Economy, Progression, Clock, Worker 능력치/체력, 하루 요약)와 공장별(Grid, Sim, Spawner, Unlocks, Trucks, Air/Fragile 상태, 집계)을 나눈다: `Company` + `FactorySite`.
- 하위 호환: 기존 코드·테스트가 쓰는 `GameSession` API는 "현재 공장"을 가리키는 얇은 파사드로 남겨 기존 테스트가 그대로 통과하게 한다(필요하면 단계적으로 옮긴다).
- 시계 한 번 틱에 모든 공장을 같은 dt로 틱. 점심·퇴근·트럭 18시 출발·09시 초기화·입고 정지가 모든 공장에 적용.
- 테스트: 공장 1개일 때 기존 결과와 동일(골든 비교), 공장 2개 동시 틱, 돈 공유, 해금 분리.

## O2 — 공장 종류와 구매
- `FactoryKind { Headquarters, Airport, Precision }`와 프로필(가격, 항공·취급주의 비율, 보상 보정, 처음부터 있는 도크). 공항: 항공 도크 처음부터, 항공 60%, 항공 정상 출고 +35. 정밀: 취급주의 50% 처음부터, 취급주의 정상 출고 +60.
- 구매 조건(직전 공장의 Plot2 + Scanner), 가격 ₩3,000 / ₩8,000, 회사 단위 해금 API.
- 판정 보상 보정은 DeliveryScoring에 공장 프로필을 넘기는 방식(전역 상수 변경 금지).
- 테스트: 조건·가격·프로필별 생성 비율(결정적 난수)·보상.

## O3 — 공장 전환과 월드
- 현재 공장 번호, 전환 API(손에 택배 있으면 거부), 작업자 위치 (1,1)로.
- WorldBuilder/CellViews/PackageViews/TruckViews/StatusBars/PlacementGhost를 현재 공장에 다시 묶는다(`SessionReplaced`와 비슷한 `FactorySwitched`). 공장별 바닥색.
- HUD: 공장 탭 알약(시계 위), Tab·LB/RB, 다른 공장 요약 칩과 경보 토스트(공장마다 30초 제한), 0.3초 페이드.
- 상점: 공장별 해금 + 회사 단위 `새 공장` 묶음. 하루 요약에 공장별 줄.

## O4 — 저장 v10
- 회사 + 공장 목록 직렬화. v6~v9 → 1공장 회사로 읽기. 검증(공장 수 1~3, 종류 중복 금지, 현재 번호 범위).
- 테스트: v10 왕복(공장 3개), v9 → v10 변환.

## O5 — 테스트와 스크린샷
- PlayMode: 구매 → 탭 생김 → 전환 시 월드 교체·작업자 위치, 손에 든 택배 거부, 배경 공장이 계속 틱(전환 후 돌아오면 택배 진행), 경보 칩.
- 스크린샷 `docs/design/unity-factories.png`(2공장 공항 물류센터 화면, 상단 공장 탭, 1공장 요약 칩)와 `unity-shop-factory.png`(상점 새 공장 묶음).

## O6 — 택배차 구매 (스펙 §20)
- 코어 `TruckFleet`를 도크별 차량 목록으로 확장(대수 1~3, 차량 상태: 도크/차고/운행 남은 시간). 교대 2분, 운행 20분, 시계 연동·18시·09시 규칙.
- 구매 API(공장별·도크별, ₩400/₩900, 최대 3, 항공 도크는 있을 때만), 상점 `택배차` 묶음.
- 뷰: 알약 문구(`12/30 · 2대`, `교대 0:02`, `다음 차 0:12`), 교대 연출(떠나는 트럭이 나가고 다음 트럭이 들어옴).
- 테스트: 1대/2대/3대 대기 시간, 운행 복귀 후 차고 대기, 점심 정지, 18시·09시, 저장 v10 왕복과 v9 변환. 스크린샷 `docs/design/unity-trucks.png` 갱신(2대 도크 교대 중 포함).
